## 经验教训 Lessons Learned

- [2026-11-10 11:07] [经验教训] GenUI: formato exacto de table.details y escaping en fences grandes — dsh-ui (GenUI) en auditorías largas: el campo `details` de `table` exige un array por fila cuyos elementos son componentes (p. ej. [{"type":"text","content":"..."}]) o null — no strings ni arrays de strings; usar `validate_dsh_ui` antes de emitir cualquier fence con tabla (los diagnósticos indican exactamente qué campo falla). Para código/diffs grandes: escribir JS con comillas simples, CSS sin comillas y atributos HTML escapados como \" dentro del JSON del fence; los saltos de línea van como \n.
- [2026-11-10 11:22] [经验教训] Mojibake por Get-Content ANSI y su reparación CP1252→UTF-8 — Pitfalls verificados en Taskify: (1) pwsh Get-Content/Set-Content corrompió la codificación UTF-8 de finanzas.html (leyó como ANSI/CP1252 → mojibake doble-encoded); la reparación fue un roundtrip por línea: texto mojibake → bytes CP1252 (con mapa de los 27 caracteres 0x80-0x9F) → decodificar UTF-8; ojo con bytes CP1252 indefinidos (0x81,0x8D,0x8F,0x90,0x9D) que aparecen como controles invisibles y rompen regex de detección simples. Para manipular texto con precisión de bytes usar Node (fs) con encodings explícitos, no pwsh. (2) js/security.js tenía anotaciones TypeScript en .js y bare import 'dompurify' → nunca parseable; node --check lo detecta; fue eliminado. (3) Los <link>/<script> dentro de fragmentos HTML inyectados vía innerHTML resuelven contra la URL de la página (no del fragmento) y no se ejecutan — no son errores reales de imports.
